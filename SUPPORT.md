# Support

This repository is a demonstration and reference implementation maintained on a best-effort basis. It does not include commercial support, uptime commitments, response-time commitments, or a remediation service-level agreement.

## Usage Questions

Use GitHub Discussions when enabled. Otherwise, open a GitHub issue for reproducible questions or defects that do not contain sensitive information.

Before opening an issue:

1. Review `README.md`, `CONFIGURATION.md`, `TESTING.md`, and `SCALABILITY.md`.
2. Run `terraform fmt -check -recursive` and `terraform validate`.
3. Remove subscription IDs, keys, tokens, Terraform state, tenant data, and other sensitive values from logs and examples.

## Security Issues

Do not report vulnerabilities or credentials through a public support issue. Follow `SECURITY.md` and use GitHub Private Vulnerability Reporting.

## Azure Support

Azure service incidents, subscription quota increases, billing questions, and platform-specific failures may require an Azure support request. This project does not replace Microsoft Azure support.
